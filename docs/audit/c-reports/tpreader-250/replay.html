The Teleport Other exclusion list read one entry too many

While scoring a Teleport Other, the Borg keeps a list of monsters it plans to banish, so their danger is not counted twice. The exclusion loop in the per-monster danger routine ran one entry past that list — into a slot holding a stale index from an earlier, longer evaluation. Any monster whose index happened to sit in that slot had its danger dropped entirely: an adjacent giant could be rated harmless while the Borg decided whether to teleport away. The correction reads only the real entries.

What the controls establish

With the giant genuinely in the list, both versions still exclude its danger; with an empty list, both count it. Those two complete logs match byte for byte, so the correction changes only the stale-read case.

Experiment conditions and limits

Native Human Warrior, seed 1000, glowing constructed arena, lit torch, an awake hill giant adjacent to the Borg (measured danger 179). The exclusion list is set directly in the state a longer earlier Teleport Other evaluation leaves behind (one real entry, one stale leftover past the count) — recorded as a fixture intervention. The production per-monster danger routine runs unmodified; no damage or survival claim beyond this one score.
