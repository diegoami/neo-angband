The message line that never ended

The Borg reads the message line from the screen as wide characters and converts it back to bytes - with a limit of one byte per wide character. A multibyte character occupies more than one byte, so a line whose byte length lands exactly on the limit was truncated without its terminating zero, and the uninitialized caller buffer was then trimmed and measured as a string: stale stack bytes parsed as message text, producing phantom monsters in the supplied replay evidence.

What the control establishes

A pure-ASCII row fits the old limit as well: both variants terminate identically with byte-identical logs - the correction changes only the multibyte boundary case.

Experiment conditions and limits

Native Human Warrior, seed one thousand, a UTF-8 locale (the multibyte conversion only widens in a multibyte locale), a hand-painted screen row of eighty characters with exactly one two-byte character, and a caller buffer deliberately junked with no zero anywhere so an unterminated conversion is visible as a full-buffer measurement. This isolates the conversion bound, not the full message-parsing chain; the phantom-monster consequence is the supplied harness evidence, not claimed here. No death or survival claim.
